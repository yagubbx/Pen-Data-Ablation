# Pen Data Ablation

Does better training data help a pen detector?
This project compares two YOLOv8n models: 16 photos with similar light backgrounds,
and 79 photos with more varied backgrounds. Both use the same training settings.

Trained weights, labeled data, test results and a live webcam comparison are included.
One live webcam test is documented in [LIVE_RESULTS.md](LIVE_RESULTS.md).

Your three phone videos are tested in [PHONE_RESULTS.md](PHONE_RESULTS.md).
They are offline tests. Private webcam images and videos are not included.
